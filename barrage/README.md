# 탄막 패링 웹 도형 시험판 (버리는 코드)

쿼터뷰 보스전 탄막 슈팅 + 흰·금 탄 패링. army-command(Unity 전쟁 게임)와 별개인 새 게임의 첫 시험판이고,
뿌리는 WSL의 Godot 시험판 `proto-game`(쿼터뷰 보스전 패링 액션)이다.

- 설계서: `docs/superpowers/specs/2026-11-16-barrage-design.md`, 계획서: `docs/superpowers/plans/2026-11-16-barrage-prototype.md`(첫 판)·`2026-11-16-barrage-ranged-boss.md`(원거리 보스 재설계).
- 실행: `python prototypes/barrage/tools/serve.py 8797` → `http://localhost:8797/`
- 시험: `node --test "prototypes/barrage/test/*.test.mjs"` (Node 22)
- `src/sim/` = 순수 계산(브라우저·Node 둘 다, 고정 120 Hz 틱), `src/view/` = 화면·입력·연출·소리.
  판정 수치는 `src/sim/rules.js`, 보이기 수치는 `src/view/look.js` 한곳.
- `out/` = 녹화(저장소 밖).


## 조작

양손 키보드 기본: 왼손 WASD·Space, 오른손 J·K·L(U·I·O는 나중 스킬 자리). Shift·Q·E·마우스도 같이 된다.

| 키 | 하는 일 |
|---|---|
| WASD / 화살표 | 이동(화면 기준, 가속·관성 없음). 사격은 늘 자동(보스 쪽으로 퍼지는 탄) |
| J / Shift / 왼쪽 클릭 | 패링 — 흰·금 탄과 흰·금 몸 공격(근접·박치기·파도·검기)을 받아친다. 빨강은 못 받는다. 그로기 보스 곁(금빛 고리가 밝을 때)이면 **처형** |
| Space / 오른쪽 클릭 | 회피(구르기) — 충전 2개, 하나는 3초에 돌아온다. 빨간 공격은 구르기로 통과 |
| K / Q | 방패(1.5초, 보라 탄만 막음) — 아이템으로 얻은 횟수만큼 |
| L / E | 폭탄(판의 탄 지움·잠깐 무적·보스 피해) — 아이템으로 얻은 횟수만큼. 맞은 직후 0.15초 안에 누르면 그 한 대를 되돌림 |
| 1 ~ 4 | 보조 무기 켜고 끄기(시험용): 1 미사일 · 2 산탄(패링할 때) · 3 빔 · 4 드론 — 처음엔 다 켜짐. 공격 무기는 **패링 뒤 3초(완벽 4.5초)만 가동** |
| U | **모은 탄 던지기**: 받아친 탄은 바로 날아가지 않고 몸 둘레에 모인다(최대 4). U를 누르면 한 번에 던져 피해·무력화를 주고 체력이 돌아온다. 가득 찬 뒤 받은 탄은 바로 날아간다. |
| U / I / O (`?store=0`) | 예전 방식의 무기 스킬(패링 게이지 3칸): 미사일 일제 사격 / 굵은 빔 / 드론 연사 |
| V | 시점 45° ↔ 60° |
| G | 패링 고리 보이기 켜기·끄기 |
| Esc | 멈춤 |
| F1 | 디버그(판정 원) |
| F2 | 수치 패널(판정·보이기 수치를 판 중에 바꿈) |
| F4 | 다시 하기 |

색 규칙: 자주 = 보통 탄(피함) · 흰 = 패링 · 금 = 마무리(패링하면 반격 기회) · 빨강 = 회피만 · 청록 = 플레이어 · 초록 = 아이템(시작 방패 1·폭탄 1, 보스전엔 25초마다 하나).
보스 몸이 번쩍이는 색 = 다음 위협 색. 바닥 장판(박치기 줄·파도 고리·검기 부채·레이저 조준선)의 색도 같은 뜻이다.

## URL

`http://localhost:8797/?seed=1&bot=1` 처럼 붙인다.

| 이름 | 뜻 |
|---|---|
| `seed` | 판 난수(같은 seed = 같은 판) |
| `bot` | 시범 봇: `1` 숙련 · `some` 가끔 패링 · `dodge` 피하기만 · `walk` 걷기만 · `turtle` 서서 패링만 |
| `phase` | `2`면 2단계(체력 50%)부터 |
| `pattern` | 그 패턴만 되풀이(1~8, 8 = 레이저) |
| `lab` | 상황 되풀이 장면: `parry` `stream` `melee` `rush` `dodge` `graze` `execute` |
| `pitch` | 시점 각도(45·60, 그 밖은 고정 확인용) |
| `bh` | 탄 높이 |
| `speed` | 게임 빠르기 배율 |
| `ring` | `0`이면 패링 고리 숨김 |
| `heal` | `1`이면 완벽 패링 회복 변형 |
| `gear` | 보조 무기: `all`(기본) · `none` · `missile,burst,beam,drone` 중 고르기 |
| `record` · `fps` | 녹화(초·프레임) — `tools/record.ps1`이 붙인다 |
| `raf` | `timer`면 숨은 창에서도 돈다(미리보기 확인용) |

## 도구

- `node prototypes/barrage/tools/botrun.mjs --seeds 10` — 화면 없이 봇 판: 종류별 승/판, 판 길이, 맞음, 패링 몫, 출처별 맞음(1~7 · 레이저 · 구슬 · 콤보 · 박치기 · 파도 · 검기 · 바탕).
- `powershell -File prototypes/barrage/tools/record.ps1 -Seconds 30 -Fps 60 -Name x -Query "bot=1&seed=1"` — 소리 든 영상 → `out/x.mp4`.

## 수동 테스트 방법

1. `python prototypes/barrage/tools/serve.py 8797` → `http://localhost:8797/?seed=1` 한 판. 처음 약 20초는 규칙을 가르치는 순서다:
   흰 가운데 부채(흰 탄 받기) → 빨간 창(빨강은 피하기) → 흰 몸통 박치기(줄 위에서 받아치기) → 다가와서 흰·흰·금 콤보(다 받으면 완전 반격).
2. 그 뒤: 보스가 쏘면서 둘레를 돌고, 약 7초(2단계 5초)마다 박치기·지면 파도·검기·다가오기 중 하나. 파도는 판 끝까지 퍼지니 흰이면 받고 빨강이면 구른다.
3. 2단계만: `?phase=2` — 쌍둥이 구슬, 진한 바탕 탄막, 새 패턴 5·6·7이 하나씩.
4. 두 번째 보스 — 몸을 돌리는 용: `?boss=dragon`(앞 = 화염구·브레스·발톱, 옆 = 날갯짓, 뒤 = 꼬리 — 서 있는 자리가 다음 공격을 정한다).
5. 모아 던지기가 기본 규칙이다(2026-11-17). 예전 방식(받자마자 날아감 + U·I·O 스킬)은 `?store=0`. `?hard=1`을 붙이면 받는 피해 1.3배. 사람 손에 맞춘 봇은 `?bot=user`.
6. 일반 스테이지: `?stage=1` — 몬스터 방 셋(사수·돌격병·포격병·방패병)을 지나며 방마다 보상 하나(무기·사용권·체력)를 고르고 끝 방에서 보스와 싸운다. 무기 없이 시작, 죽으면 R로 그 방부터 다시(F4 = 처음부터). `&room=3`이면 그 방에서 시작(연습용). 설계 `docs/superpowers/specs/2026-11-17-barrage-stage-design.md`.
7. 기본 판(2026-11-17 낮에 올림): 무기가 늘 나가고 패링하면 과열(`always`), 몬스터가 공격을 돌아가며 씀(`vary`), I·F 누르고 있기 = 저격(`snipe`). `?try=none`이면 이 셋을 끈 예전 판, `?try=-snipe`처럼 하나만 뺄 수 있다.
8. 실험 기믹(기본 판에 더 켠다): `?try=이름,이름` — `rope`·`sky`(갈고리 이동, I·F) · `dash`(돌진 베기) · `swap`(자리 바꾸기, I·F) · `pillars`(엄폐 기둥) · `fire`(불 장판) · `crystal`(수정) · `focus`(집중 사격) · `lance`(꿰뚫는 던지기) · `mine`(지뢰, I·F) · `orbit`(오라) · `graze`(스침 모으기) · `bubble`(보스 보호막) · `tide`(밀물) · `always`(무기가 늘 나가고 패링하면 과열) · `hunt`(나를 겨눈 탄은 보라, 그 옆이 흰색) · `snipe`(I·F 누르고 있기: 시간이 느려지고 겨눈 적에 조준점이 붙는다 — WASD로 그쪽의 가까운 적을 고르고 떼면 모은 탄을 쏜다) · `vary`(몬스터가 공격을 돌아가며 쓴다). 실험 스테이지 `?stage=2`(자폭병·보호탑·버티기 방). 기록 `docs/superpowers/specs/2026-11-17-barrage-experiments.md`.
9. 한 동작씩 연습: `?lab=parry` · `?lab=stream` · `?lab=melee` · `?lab=rush` · `?lab=dodge` · `?lab=graze` · `?lab=execute`(그로기 처형 — 다가가 Shift).
10. 시작 장면(보스 이름, 약 1초)은 아무 키로 건너뛰고, `?intro=0`이면 없다. 소리 끄기는 `?mute=1`.
11. 시점은 V, 고리는 G, 회복 변형은 `?heal=1`.
