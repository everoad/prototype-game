# 탄막 패링 웹 도형 시험판 (버리는 코드)

쿼터뷰 보스전 탄막 슈팅 + 흰·금 탄 패링. army-command(Unity 전쟁 게임)와 별개인 새 게임의 첫 시험판이고,
뿌리는 WSL의 Godot 시험판 `proto-game`(쿼터뷰 보스전 패링 액션)이다.

- 설계서: `docs/superpowers/specs/2026-11-16-barrage-design.md`, 계획서: `docs/superpowers/plans/2026-11-16-barrage-prototype.md`(첫 판)·`2026-11-16-barrage-ranged-boss.md`(원거리 보스 재설계).
- 실행: `python prototypes/barrage/tools/serve.py 8797` → `http://localhost:8797/`
- 시험: `node --test "prototypes/barrage/test/*.test.mjs"` (Node 22)
- `src/sim/` = 순수 계산(브라우저·Node 둘 다, 고정 120 Hz 틱), `src/view/` = 화면·입력·연출·소리.
  판정 수치는 `src/sim/rules.js`, 보이기 수치는 `src/view/look.js` 한곳.
- `out/` = 녹화(저장소 밖).


## 조작

양손 키보드: 왼손 WASD·Space·Q·E, 오른손 윗줄 U·I·O = 공격, 가운뎃줄 J·K·L = 패링·이동기. Shift·마우스도 같이 된다(2026-11-17 한 판의 뼈대 — F는 뺐고 K·L은 방패·폭탄이 아니다).

| 키 | 하는 일 |
|---|---|
| WASD / 화살표 | 이동(화면 기준, 가속·관성 없음). 사격은 늘 자동(보스 쪽으로 퍼지는 탄) |
| J / Shift / 왼쪽 클릭 | 패링 — 흰·금 탄과 흰·금 몸 공격(근접·박치기·파도·검기)을 받아친다. 빨강은 못 받는다. 그로기 보스 곁(금빛 고리가 밝을 때)이면 **처형** |
| Space / 오른쪽 클릭 | 회피(구르기) — 충전 2개, 하나는 3초에 돌아온다. 빨간 공격은 구르기로 통과 |
| Q | 방패(1.5초, 보라 탄만 막음) — 얻은 횟수만큼 |
| E | 폭탄(판의 탄 지움·잠깐 무적·보스 피해) — 얻은 횟수만큼. 맞은 직후 0.15초 안에 누르면 그 한 대를 되돌림 |
| 1 ~ 4 | 보조 무기 켜고 끄기(시험용): 1 미사일 · 2 산탄(패링할 때) · 3 빔 · 4 드론 — 처음엔 다 켜짐. 공격 무기는 **패링 뒤 3초(완벽 4.5초)만 가동** |
| U | **모은 탄 던지기**: 받아친 탄은 바로 날아가지 않고 몸 둘레에 모인다(최대 4). U를 누르면 한 번에 던져 피해·무력화를 주고 체력이 돌아온다. 가득 찬 뒤 받은 탄은 바로 날아간다. |
| I (누르고 있기) | **저격**: 시간이 느려지고 겨눈 적에 조준점이 붙는다. WASD로 그쪽의 적을 고르고, 떼면 모은 탄을 다 써서 줄 위의 적을 모두 뚫는다(회피 = 취소) |
| O | **탄 기술**(카드로 얻는다 — 키가 필요한 것): 지뢰 = 모은 탄 하나를 발밑에 놓는다 |
| K / L | **이동기**(카드로 얻는다 — 얻은 차례대로 K, L): 갈고리 = 가는 쪽 말뚝으로 날아간다 · 자리 바꾸기 = 겨눈 몬스터와 자리를 바꾼다 |
| U / I / O (`?store=0`) | 예전 방식의 무기 스킬(패링 게이지 3칸): 미사일 일제 사격 / 굵은 빔 / 드론 연사 |
| V | 시점 45° ↔ 60° |
| G | 패링 고리 보이기 켜기·끄기 |
| Esc | 멈춤 |
| F1 | 디버그(판정 원) |
| F2 | 수치 패널(판정·보이기 수치를 판 중에 바꿈) |
| F4 | 다시 하기 |

색 규칙: 자주 = 보통 탄(피함) · 흰 = 패링 · 금 = 마무리(패링하면 반격 기회) · 빨강 = 회피만 · 청록 = 플레이어 · 초록 = 아이템(시작 방패 1·폭탄 1, 보스전엔 25초마다 하나).
보스 몸이 번쩍이는 색 = 다음 위협 색. 바닥 장판(박치기 줄·파도 고리·검기 부채·레이저 조준선)의 색도 같은 뜻이다.

## URL

`http://localhost:8797/?seed=1&bot=1` 처럼 붙인다.

| 이름 | 뜻 |
|---|---|
| `char` | `sword` = 검사(근접 캐릭터 — 약한 사격, 무기 없음, 모은 칸을 U 일섬 · I 회전 베기 · O 마무리로 쓴다). 없으면 사수 |
| `seed` | 판 난수(같은 seed = 같은 판) |
| `bot` | 시범 봇: `1` 숙련 · `some` 가끔 패링 · `dodge` 피하기만 · `walk` 걷기만 · `turtle` 서서 패링만 · `script` 연습 장면의 정해진 손(`clip=`) |
| `phase` | `2`면 2단계(체력 50%)부터 |
| `pattern` | 그 패턴만 되풀이(1~8, 8 = 레이저) |
| `lab` | 상황 되풀이 장면: `parry` `stream` `melee` `rush` `dodge` `graze` `execute` · 이기어검의 움직임을 보는 장면 `swords`(가만히 선 보스) `swordmobs`(가만히 선 몬스터 넷) — `char=sword&bot=script&clip=idle\|chain\|slash\|spin\|finish\|burst\|stack\|gap\|forms`과 같이 쓴다 |
| `pitch` | 시점 각도(45·60, 그 밖은 고정 확인용) |
| `bh` | 탄 높이 |
| `speed` | 게임 빠르기 배율 |
| `ring` | `0`이면 패링 고리 숨김 |
| `heal` | `1`이면 완벽 패링 회복 변형 |
| `gear` | 보조 무기: `all`(기본) · `none` · `missile,burst,beam,drone` 중 고르기 |
| `record` · `fps` | 녹화(초·프레임) — `tools/record.ps1`이 붙인다 |
| `raf` | `timer`면 숨은 창에서도 돈다(미리보기 확인용) |

## 도구

- `node prototypes/barrage/tools/botrun.mjs --seeds 10` — 화면 없이 봇 판: 종류별 승/판, 판 길이, 맞음, 패링 몫, 출처별 맞음(1~7 · 레이저 · 구슬 · 콤보 · 박치기 · 파도 · 검기 · 바탕).
- `powershell -File prototypes/barrage/tools/record.ps1 -Seconds 30 -Fps 60 -Name x -Query "bot=1&seed=1"` — 소리 든 영상 → `out/x.mp4`.

## 수동 테스트 방법

1. `python prototypes/barrage/tools/serve.py 8797` → `http://localhost:8797/?seed=1` 한 판. 처음 약 20초는 규칙을 가르치는 순서다:
   흰 가운데 부채(흰 탄 받기) → 빨간 창(빨강은 피하기) → 흰 몸통 박치기(줄 위에서 받아치기) → 다가와서 흰·흰·금 콤보(다 받으면 완전 반격).
2. 그 뒤: 보스가 쏘면서 둘레를 돌고, 약 7초(2단계 5초)마다 박치기·지면 파도·검기·다가오기 중 하나. 파도는 판 끝까지 퍼지니 흰이면 받고 빨강이면 구른다.
3. 2단계만: `?phase=2` — 쌍둥이 구슬, 진한 바탕 탄막, 새 패턴 5·6·7이 하나씩.
4. 두 번째 보스 — 몸을 돌리는 용: `?boss=dragon`(앞 = 화염구·브레스·발톱, 옆 = 날갯짓, 뒤 = 꼬리 — 서 있는 자리가 다음 공격을 정한다).
5. 모아 던지기가 기본 규칙이다(2026-11-17). 예전 방식(받자마자 날아감 + U·I·O 스킬)은 `?store=0`. `?hard=1`을 붙이면 받는 피해 1.3배. 사람 손에 맞춘 봇은 `?bot=user`.
6. **한 판의 뼈대**(2026-11-17): `?stage=1`(보스 수호자) · `?stage=2`(보스 용) — 방 넷 + 보스, 5분 안쪽. 방 3은 특수 방(스테이지 1 = 버티기 40초, 스테이지 2 = 정예 돌격병 + 졸개), 방 4에는 방의 특징(기둥 · 밀물)이 붙는다. 미사일 하나를 들고 시작해, 방을 깰 때마다 **카드 둘 + 보급 하나** 가운데 하나를 걸어가서 줍는다(자리 위에 잠깐 서 있어야 주워진다 — 지나가기만 해서는 안 주워진다). 카드는 네 갈래 — 무기 2칸 · 탄 기술 1칸 · 이동기 2칸 · 몸(제한 없음) — 이고 스테이지가 끝나면 다 사라진다. 칸이 찬 갈래의 카드를 밟으면 밟은 자리가 "무르기", 나머지 자리가 지금 낀 카드가 된다(버릴 카드로 걸어가면 바뀐다 — 자리는 한 번 벗어났다 돌아와야 눌린다). 탄을 쓰면(U 던지기 · I 저격 · O 지뢰) 낀 무기가 **한 방**을 같이 낸다(쓴 칸 수만큼). 끝나면 등급(S·A·B·C — 싸운 시간·맞은 횟수·다시 한 횟수, 카드를 고르는 시간은 세지 않는다)과 최고 기록(브라우저에 저장)이 뜬다. 죽으면 R로 그 방부터 다시(F4 = 처음부터, 카드가 새로 뽑힌다). `&room=3`이면 그 방에서 시작, `&kit=burst,sky`면 그 카드를 들고 시작, `&seed=7`이면 그 카드 차례로(셋 다 연습용 — **기록은 주소에 `stage`와 화면 옵션(`mute`·`raf`·`intro`·`ring`·`pitch`·`bh`)만 붙은 판에만 남는다**). 설계 `docs/superpowers/specs/2026-11-17-barrage-run-design.md`(잰 수치는 §12), 몬스터는 `…-barrage-stage-design.md`.
7. 기본 판(2026-11-17 낮에 올림): 무기가 늘 나가고 패링하면 과열(`always`), 몬스터가 공격을 돌아가며 씀(`vary`), I 누르고 있기 = 저격(`snipe`). `?try=none`이면 이 셋을 끈 예전 판, `?try=-snipe`처럼 하나만 뺄 수 있다. 보스전만 여는 판은 무기 칸 규칙대로 **미사일 + 산탄**을 들고 시작한다(`?gear=all`이면 넷, 예전 판 `?try=none`은 넷 그대로).
8. 실험 기믹(기본 판에 더 켠다): `?try=이름,이름` — `sky`(갈고리, K — 끌려가는 동안은 안 맞는다) · `dash`(돌진 베기) · `swap`(자리 바꾸기, K — 갈고리와 같이 켜면 L) · `pillars`(엄폐 기둥) · `lance`(꿰뚫는 던지기) · `mine`(지뢰, O) · `orbit`(오라) · `graze`(스침 모으기) · `bubble`(보스 보호막) · `tide`(밀물) · `always`(무기가 늘 나가고 패링하면 과열) · `snipe`(I 누르고 있기: 시간이 느려지고 겨눈 적에 조준점이 붙는다 — WASD로 그쪽의 가까운 적을 고르고 떼면 모은 탄을 쏜다) · `vary`(몬스터가 공격을 돌아가며 쓴다). 스테이지 2 `?stage=2`(자폭병 · 정예 · 밀물). 기록 `docs/superpowers/specs/2026-11-17-barrage-experiments.md`.
9. 한 동작씩 연습: `?lab=parry` · `?lab=stream` · `?lab=melee` · `?lab=rush` · `?lab=dodge` · `?lab=graze` · `?lab=execute`(그로기 처형 — 다가가 Shift).
10. 시작 장면(보스 이름, 약 1초)은 아무 키로 건너뛰고, `?intro=0`이면 없다. 소리 끄기는 `?mute=1`.
11. 시점은 V, 고리는 G, 회복 변형은 `?heal=1`.
12. **검사**(2026-11-17, 스킬 셋만 — 설계 `docs/superpowers/specs/2026-11-17-barrage-sword-design.md`): `?char=sword`(보스전, 용은 `&boss=dragon`) · `?stage=1&char=sword`.
    지금 판(설계 §18): 주 무기는 **쌍검**이다. 기본 공격은 좌우 칼이 번갈아 내는 **칼바람**이고 사거리가 있다(보스 가운데에서 7 U쯤 — 그 안에서 싸운다). 칼바람이 맞는 동안 칸이 조금씩 차고(6초에 한 칸), **내 둘레 4.5 U 안의 적 탄은 절반 속도로 느려진다.**
    받아쳐 칸을 모으고, **U 일섬**(한 칸 — 겨눈 적을 베며 뚫고 건너편에 선다, 가는 동안 무적) · **I 회전 베기**(한 칸 — 몸 둘레, 무적 없음, 무너짐이 가장 많이 찬다) · **O 마무리**(남은 칸 전부 — 앞을 베고 뒤로 튕겨 나온다, 무적)로 쓴다. 칸을 쓸 때마다 회복된다.
    볼 것: 건너편(작은 청록 표시)이 비었는지 읽고 들어가게 되는가, 붙어서 받아치며 이어 치게 되는가, 억울하게 맞지 않는가. 스테이지에서는 이동기·몸 카드만 뜬다. 기록은 남지 않는다.
    재기: `node prototypes/barrage/tools/botrun.mjs --kinds user --seeds 10 --char sword [--boss dragon | --stage 1]`.
    **이기어검**(검사의 무기 — 설계 `docs/superpowers/specs/2026-11-17-barrage-flying-swords-design.md`, 판정 `src/sim/swords.js`, 그리기 `src/view/swordsView.js`): 검 다섯 자루가 늘 떠 있다. 사거리 안에 적이 있으면 모두 나가서 돌아오지 않고 0.5초에 한 번씩 번갈아 찌른다(적 사이를 오가고, 혼자면 그 적을 돌며). 스킬이 적을 벨 때마다 다섯 자루가 더 생겨 4초 남고(열다섯까지), **가진 검이 모두 그 스킬을 따라 벤다** — 일섬은 내 줄과 나란히, 회전 베기는 난무, 마무리는 나와 함께 물러났다가 착지하며 차례로 쏜다. 검은 무너짐을 주지 않고 칸도 채우지 않는다.
    움직임 보기: `?char=sword&lab=swords&bot=script&clip=burst`(주소에 `join=0` = 스킬에 새 다섯만 나서게 — 견줘 보는 용). 느린 영상: `tools/record.ps1 -Fps 120 -Slow 4 -Query "char=sword&lab=swords&clip=spin&bot=script&mute=1"`(판과 효과가 같이 느려진다 — `speed=`는 판만 느려진다).
    봇(수호자 40판, 2026-11-17): 검사 29승 · 이긴 판 68초(사수 31승 · 65초). 용 20판: 검사 18승 · 54초(사수 14승 · 54초).
    **일섬의 형태**(2026-11-18 시험판 — 설계 `docs/superpowers/specs/2026-11-18-barrage-run-growth-design.md` §3·§8, 카드는 나중): 주소에 `&slash=chain`(잇는 일섬 — 한 칸으로 세 번, 선 뒤 0.6초 안에 U를 다시) · `&slash=deep`(깊은 일섬 — 한 번에 세게, 선 뒤 0.3초는 다른 스킬이 기다린다).
    움직임 보기: `?char=sword&slash=chain&lab=swordmobs&bot=script&clip=forms`(몬스터 사이를 건너다닌다) · `&lab=swords`(보스를 되지나간다).
